# دروسي

موقع خاص وبسيط: تفتحه المعلمة من جوالها، تختار الدرس، فيفتح ملف PowerPoint من Google Drive.

- موقع ثابت: HTML و CSS و JavaScript فقط، بلا إطار عمل ولا خطوة بناء.
- مستضاف مجاناً على GitHub Pages.
- كل البيانات (الأسماء، عناوين الدروس، روابط Google Drive) مشفّرة برمز دخول. الملف المرفوع هو `content/data.enc.json` فقط.

## قاعدتان لا تُكسران

1. الملف `content/data.json` لا يُرفع أبداً إلى GitHub (موجود في `.gitignore`).
2. رمز الدخول لا يُكتب في أي ملف داخل المشروع.

المستودع علني، وأي شخص يستطيع تنزيل الملف المشفّر ومحاولة تخمين الرمز على جهازه، لذلك اختر رمزاً طويلاً (١٠ خانات فأكثر، أو جملة قصيرة) لا رمزاً من أربعة أرقام.

---

## ١. رفع ملفات PowerPoint إلى Google Drive ونسخ الرابط

1. افتح [drive.google.com](https://drive.google.com) وارفع ملفات الدروس (يفضّل في مجلد واحد لكل فصل).
2. اضغط على الملف بالزر الأيمن ثم **مشاركة** (Share) ← **مشاركة**.
3. تحت **الوصول العام** اختر **أي شخص لديه الرابط** (Anyone with the link) بصلاحية **عارض** (Viewer).
4. اضغط **نسخ الرابط** (Copy link).

كرّر ذلك لكل ملف. الرابط يبدأ بـ `https://`، ولكل ملف رابط مختلف: تأكد أنك نسخت رابط الملف الصحيح قبل لصقه.

## ٢. لصق الروابط في `content/data.json`

افتح `content/data.json` بأي محرر نصوص، وضع كل رابط بين علامتي التنصيص في خانة `link` للدرس المناسب:

```json
{ "type": "lesson", "title": "الدرس ١: قصص الجمع", "pages": "١١٤ - ١١٥", "file": "٠٢_الدرس_١_قصص_الجمع.pptx", "link": "https://docs.google.com/presentation/d/..." }
```

- خانة `file` للتذكير باسم الملف فقط، ولا تظهر في الموقع.
- الدرس الذي يبقى رابطه فارغاً `""` يظهر في الموقع بعلامة «قريباً».

إن لم يكن الملف موجوداً (جهاز جديد مثلاً) فانسخ `content/data.example.json` إلى `content/data.json` وعدّله.

## ٣. التشفير ثم الرفع إلى GitHub

يلزم وجود [Node.js](https://nodejs.org) (الإصدار ١٨ أو أحدث). لا حاجة لـ `npm install`.

```bash
npm run encrypt
```

سيطلب رمز الدخول مرتين (لا يظهر أثناء الكتابة)، ثم ينشئ `content/data.enc.json`. بعدها:

```bash
git add -A
git commit -m "تحديث الدروس"
git push
```

يتحدّث الموقع خلال دقيقة أو دقيقتين.

- إذا استخدمت الرمز نفسه، تبقى الأجهزة التي فعّلت «تذكّريني» مسجّلة دون إعادة إدخاله.
- إذا غيّرت الرمز، سيُطلب الرمز الجديد مرة واحدة على كل جهاز.
- للمعاينة على جهازك قبل الرفع: `npm run preview` ثم افتح `http://localhost:4173`.

## ٤. إضافة مادة أو فصل أو درس

البيانات مرتبة هكذا: **مواد ← فصول ← دروس**.

```json
{
  "teacher": { "name": "…", "greetingName": "…", "school": "…" },
  "subjects": [
    {
      "id": "math",
      "title": "الرياضيات",
      "grade": "الصف الأول الابتدائي",
      "icon": "math",
      "chapters": [
        {
          "id": "ch6",
          "title": "الفصل السادس: الجمع",
          "lessons": [ { "type": "lesson", "title": "…", "pages": "…", "file": "…", "link": "" } ],
          "fullFile": { "title": "الفصل كامل في ملف واحد", "file": "…", "link": "" }
        }
      ]
    }
  ]
}
```

**درس جديد:** أضف سطراً داخل `lessons` في مكانه من الترتيب. قيم `type` المتاحة:

| القيمة | المعنى | الشكل |
|---|---|---|
| `opener` | افتتاحية وتهيئة | نجمة، لون رملي |
| `lesson` | درس | رقم الدرس، لون أخضر مزرق |
| `test` | اختبار | لوح اختبار، لون أزرق هادئ |
| `review` | مراجعة | سهمان دائريان، لون بنفسجي هادئ |
| `game` | لعبة | نرد، لون وردي ترابي |

رقم الدرس الظاهر في البطاقة يؤخذ من العنوان إذا بدأ بـ «الدرس ٣: …».

**فصل جديد:** أضف كائناً جديداً داخل `chapters` بنفس الشكل (`id` و `title` و `lessons`، و `fullFile` اختياري). تظهر الفصول تحت بعضها في صفحة المادة.

**مادة جديدة:** أضف كائناً جديداً داخل `subjects` بمعرّف `id` إنجليزي فريد (مثل `science`)، و `icon` إما `math` أو `book`. تظهر بطاقتها تلقائياً في الصفحة الرئيسية.

بعد أي تعديل: انتبه للفواصل `,` بين العناصر، ثم نفّذ الخطوة ٣. إن كان في الملف خطأ فسيخبرك `npm run encrypt` قبل التشفير.

## ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` و `css/style.css` و `js/app.js` | الموقع |
| `content/data.json` | البيانات الأصلية — **على جهازك فقط** |
| `content/data.enc.json` | البيانات المشفّرة — هذا ما يُرفع |
| `content/data.example.json` | مثال على شكل البيانات |
| `scripts/encrypt.mjs` | التشفير: AES-256-GCM بمفتاح مشتق عبر PBKDF2-SHA256 (٦٠٠ ألف دورة) |
| `scripts/serve.mjs` | خادم المعاينة المحلي |
| `scripts/make-icons.mjs` | توليد أيقونات التطبيق (`npm run icons`) |
| `manifest.webmanifest` و `icons/` | إعدادات الإضافة إلى الشاشة الرئيسية |

احتفظ بنسخة احتياطية من `content/data.json` في مكان خاص، فهو غير محفوظ في GitHub.
